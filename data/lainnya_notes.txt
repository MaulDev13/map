# Sample Text Project

This is a plain **.txt** file. Open it in any editor and it is still
perfectly readable — but the viewer renders a light *markup* layer on top
so it can have real typography, images, and links.

## Typography

You get **bold**, *italic*, and `inline code` inside normal paragraphs.
Headings go from `#` (biggest) down to `######` (smallest).

## Safety

Anything that is not a supported marker is shown literally, e.g.
`<script>alert("hi")</script>` stays harmless text.

To add more docs: drop a `.txt` in /data and run `npm run manifest`.
